# 📖 巧虎書 Chiaohu Book：自己作主的 SillyTavern 記憶插件

**📖 巧虎書 Chiaohu Book**
自己選樓層寫大綱、自己挑大綱做整合的 SillyTavern 記憶插件。

長篇角色扮演最怕兩件事：AI 忘記以前發生過什麼，以及記憶插件自己亂動你的聊天。
巧虎書只做三件事，而且每一步都由你決定：

✍️ **產生大綱**：填起始層和結束層，把那段劇情寫成一條大綱存進世界書
📋 **手動新增**：API 掛了？用別的 AI 生成後貼進來，格式完全一樣
🧩 **產生整合**：勾選幾條大綱合併成一條，原本的大綱只停用不刪除，隨時查得到

**為什麼做這個插件**

🙈 **不碰隱藏樓層**
直接讀聊天紀錄，被隱藏的樓層也讀得到，不會執行 /hide、/unhide。跟 HORAE 這類會自動隱藏樓層的插件一起用，也不會失敗後把樓層全部打開。

🪟 **搬窗不打架**
每條大綱都記得自己是哪個聊天產生的。開新窗後從 0 層重新算，也不會被舊窗的記憶擋住。

🔢 **樓層隨你填**
不會卡在「下一段要從第 61 層開始」。想跳過、想重做、想補前面的都可以；樓層重疊只提醒，不阻擋。

🕰️ **讀取 HORAE 時間地點**
直接讀 HORAE 已經整理好的日期、時間、地點，只在有變化的地方標一行。原本的狀態標籤會移除，大綱的時間準，也省 Token。

✂️ **太長自動建議拆段**
範圍跨好幾天，會建議「一天一篇」怎麼拆，也可以改成依 Token 上限拆。規劃在你的電腦上完成，不花 Token。

💰 **送出前先看 Token**
選好範圍就顯示預估 Token，開頭、結尾的內容也會列出來，確認沒選錯再送。

🔌 **各自指定 API**
大綱和整合可以各選一個 ST 連線設定檔，例如用便宜的模型寫大綱、用好的模型做整合，不會切換你正在聊天的 API。

**安裝**
擴充功能 → 安裝擴充功能，貼上：
https://github.com/wowdog0987/ST-chiaohubook

裝好後從左下角魔杖選單打開「巧虎書」。
需要 SillyTavern 1.12 以上的版本，MIT 授權，歡迎回報問題和建議。
