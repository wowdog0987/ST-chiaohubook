# 📖 巧虎書 Chiaohu Book

一個精簡的 SillyTavern 記憶插件：**你自己選樓層產生大綱，再勾選大綱合併成整合**，全部存進世界書。

沒有自動排程，也不碰樓層的隱藏狀態，可以跟 HORAE 時光記憶這類自動備份、自動隱藏的插件一起用，不會互相干擾。

## 功能

| 分頁 | 做什麼 |
|---|---|
| **產生大綱** | 填起始層和結束層，把那段聊天寫成一條大綱 |
| **手動新增** | 把其他 AI 生成的大綱貼進來（也可以直接貼 JSON），格式跟插件生成的一樣 |
| **產生整合** | 勾選幾條大綱合併成一條整合；被整合的大綱會停用，但不會刪除 |
| **設定** | API、提示詞、世界書條目設定 |

## 特色

- **不改動隱藏狀態**：直接讀聊天紀錄，已隱藏的樓層也讀得到，不會跑 `/hide`、`/unhide`。
- **搬窗不打架**：每條大綱都會記錄它是哪個聊天產生的，建議樓層和重疊提醒只看目前這個聊天。
- **樓層隨你填**：不會鎖住「下一段要從哪層開始」，預設值只是幫你先填好；樓層重疊時只提醒，不會擋住。
- **讀取 HORAE 的時間地點**：直接讀 HORAE 已經解析好的日期、時間、地點，只在有變化的地方插入一行 `【時間：1890-09-15 下午｜地點：溫室花園】`。原本的 `<horae>` 標籤會移除，節省 Token。
- **自動建議拆段**：範圍太長時，會在送出前先規劃怎麼拆，不花 Token。可以選依日期（一天一篇）或依 Token 上限拆。
- **送出前預估 Token**：選好範圍就會顯示大概會花多少 Token。
- **各自指定 API**：大綱和整合可以各選一個 ST 連線設定檔，不會切換你正在聊天的 API。
- **失敗可以重試**：遇到 429 或其他錯誤時可以直接重試，也可以改用其他 AI 生成，再用「手動新增」貼上。
- **依時間排序**：大綱的順序值等於編號，整合的順序值等於它涵蓋的大綱中最小的編號，放進提示詞時會由早到晚排列。
- **讀得到舊的記憶書條目**：[Memory Books](https://github.com/aikohanasaki/SillyTavern-MemoryBooks) 產生的舊大綱會出現在整合清單裡，可以拿來整合。

## 安裝

需要 SillyTavern 1.12 以上的版本（作者使用 1.18.0），以及內建的「連線設定檔」（Connection Manager）功能。

**方法一：在 ST 裡安裝**

擴充功能 → 安裝擴充功能，貼上：

```
https://github.com/wowdog0987/ST-chiaohubook
```

**方法二：手動安裝**

下載後，把資料夾放到 `SillyTavern/data/<使用者>/extensions/` 底下，重新整理 ST。

裝好後，從左下角魔杖選單點「巧虎書」開啟面板。

## 使用方式

1. 在**設定**頁選好大綱和整合要用的 API（連線設定檔）。
2. 到**產生大綱**頁，填起始層和結束層。下面會顯示範圍內有幾層、開頭結尾的內容、HORAE 時間和預估 Token。
3. 按「產生大綱」，確認預覽沒問題後寫入世界書。如果聊天還沒綁定世界書，會自動建立一本並綁定。
4. 累積幾條大綱後，到**產生整合**頁勾選要合併的大綱，按「產生整合」。

樓層號碼跟 ST 訊息上顯示的 `#` 一樣，從 0 開始算。

## 條目標題格式

```
[大綱 005] 61-80層 - 標題
[整合 02] 大綱003-005 - 標題
[整合 03] 大綱006,008,009 - 標題    ← 編號不連續時
```

整合條目會在隱藏欄位裡記錄來源大綱，被停用的大綱也會記錄是被哪一條整合停用的。這些資訊不會放進條目內容，不會多花 Token。

## 設定說明

| 設定 | 說明 |
|---|---|
| 大綱用／整合用 API | 選 ST 的連線設定檔；選「目前酒館 API」就用你正在用的 |
| 生成後先預覽 | 寫入前先顯示可編輯的預覽。AI 回的不是有效 JSON 時一定會顯示 |
| 讀取已隱藏的樓層 | 預設開啟 |
| 從 HORAE 讀取時間／地點 | 預設開啟，沒裝 HORAE 也不影響 |
| 拆段方式 | 依日期（預設）或依 Token |
| 單段 Token 上限 | 預設 6000 |
| 送出前移除的內容 | 每行一條正則表達式，預設移除 `<think>` 和 `<horae…>` 標籤 |
| 觸發方式 | 關鍵字＋向量（預設）、只用關鍵字、常駐 |
| 插入位置 | 預設「角色定義之前」 |
| 提示詞 | 大綱和整合各一份，可以修改。沒改過的話，插件更新時會自動套用新版 |

## 預設提示詞的風格

預設提示詞的目標是讓角色日後被提起「我們那次……」時，能說出當時發生了什麼：

- 一件事寫成一條，起因、經過、結果寫在一起；搭話、道別這類過場動作不記。
- 只保留承諾、約定、告白、決定性的話這類關鍵原句，寫在所屬事件的那一條裡。
- 日期一律寫 `YYYY-MM-DD`，不用「今天」「昨天」這種相對說法。

想要不同的風格，可以在設定頁直接改提示詞。
